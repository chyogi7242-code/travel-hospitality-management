# Travel & Hospitality - Hotel Reservation Engine

## Overview

A full-stack hotel reservation system developed using Spring Boot and React.

The application allows customers to book rooms, view reservations, cancel bookings, and provides an admin interface to manage reservation status.

---

## Tech Stack

### Backend
- Java 21
- Spring Boot 3
- Spring Data JPA
- Spring Security
- PostgreSQL
- Maven

### Frontend
- React
- Vite
- React Router
- Axios

---

## Features

### Customer Module

- Create reservations
- View reservations
- View reservation details
- Cancel reservations

### Admin Module

- View all reservations
- Pagination
- Update reservation status
- Cancel reservations
- Search reservations
- Filter reservations by status

### Authentication

- User registration
- User login
